What stays on this device

Only the named staff test uses this store. Its original attempt record contains the actor account ID, opaque window ID, member request code, approved review digest, account generation, signed session version and expiry, and the original local reservation and cleanup times. It contains no authentication cookie, account birth nonce, signing key or Discord token.

Personal details have a fixed 365-day deadline from their first reservation and are removed when these local browser controls next run. An unavailable page, blocked script or offline device cannot run this cleanup. You can remove those details now. Cleanup replaces the record with only the opaque window ID and a spent guard, including when a write remains uncertain. That guard does not expire automatically because a browser clock cannot establish new write authority; the original window stays held.

Server-side account erasure cannot reach IndexedDB on your device or a downloaded copy. Local cleanup neither erases the server's record nor settles an uncertain write. These controls grant no account, staff, signing or guild access. Clearing all site data in your browser's settings also clears the guard and local signing keys; it does not authorize retrying a past request.
