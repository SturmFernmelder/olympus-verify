# Original entry capture and the additive source restriction

`BETA_RESET_SOURCE_EPOCH` is absent by default. Its presence is a restriction on the twelve fixed beta roles in the fixed beta guild, never permission to grant, remove, or reuse those IDs. The canonical label has the `olympus-full-release-` prefix. Malformed, accessor, inherited, changed, or removed descriptors stay held; getters are not invoked. Disjoint fresh role IDs and another guild keep their original behavior.

The binding is additive because historical `BETA_RESET_DISPATCH_SEAL_MODE=v1` assertions preserve grant/discovery behavior before a seal while already holding old removal dispatch. With the new binding absent, grant SQL is returned byte-for-byte unchanged. The added closure profile holds fixed-target grant intent creation, consuming claims, and the final pre-effect decision, and holds raw removers. A central removal may still perform existing GET-only reconciliation or record an ACK-free absence. An acknowledged or unknown operation keeps its original custody predicates.

One branded capture is taken synchronously in the actual `fetch` or scheduled entry. The same pair travels through site/admin/QR dispatch, interaction actor binding, watcher ingest, roster promotion/departure, restore/backfill, rank continuation, and compensation. Direct exported seams capture before their own first await when no original pair is supplied. The reset slice receives the original scheduled pair before schema work; its grant-policy capture carries the original descriptor witness separately from policy/currentness predicates.

The source binding does not establish a provider drain, restore barrier, a seal, or `roleReuseReady`. The separate source-closure module keeps production issuance refused without actual installed authority. Counts, GET absence, and elapsed quiet time do not replace that authority. Reset removal remains separately disabled before the fixed cutoff or without explicit arming; erasure remains paused.

`beta_source_epoch_entry_test.cjs` exercises the actual source over SQLite with simulated Discord, including the admitted interaction actor-binding await, removed accessor/inherited descriptors, all twelve consuming SQL targets, fresh-role exclusion, and grant entries held before SQL or HTTP. It supplements the unchanged dispatch, central Item15, and old-removal regression suites. It is not deployment, production-drain, or source-reuse qualification.
