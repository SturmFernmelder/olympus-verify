OlympusProbe 0.1.3 - one-session probe of the Classic Forever beta addon API (installed 17 Sep 2026).
Read-only: it records which API functions exist, name/realm formats, guild roster shape and whisper
argument shapes into WTF\Account\<account>\SavedVariables\OlympusProbe.lua.
In game:  /olp test   (restriction test; click Ignore on the "blocked" popup - that popup IS the result)
          /olp note (SetNote alone, own entry, unchanged) - /olp multi (3 invites, one key press) - /olp reloadtest - /olp guild - /olp exists <name>
          /olp doc GuildInfo   and   /olp doc ChatInfo   (dump Blizzard's API documentation)
          then /reload or log out so the file is written.
Delete this folder when the beta test is over.
